## 🛠️ Tecnologías utilizadas

Para desarrollar mi portafolio profesional he utilizado diferentes tecnologías y herramientas web:

* **HTML5** — estructura y contenido del sitio.
* **CSS3** — diseño, estilos, distribución y adaptación responsive.
* **JavaScript** — interactividad, funcionalidades dinámicas, comportamiento de componentes y lógica del sitio.
* **Git** — control de versiones y gestión del código.
* **GitHub** — almacenamiento y administración del repositorio.
* **GitHub Pages** — publicación y alojamiento del portafolio.

### 💻 Stack principal

```text
HTML5
CSS3
JavaScript
Git
GitHub
GitHub Pages
```

El uso combinado de **HTML5, CSS3 y JavaScript** permite construir una experiencia web moderna, responsive e interactiva, mientras que Git y GitHub facilitan el control, mantenimiento y publicación del proyecto.
