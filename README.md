## 📌 Descripción

**Perfil Profesional** es un sitio web diseñado para entregar una presentación profesional, ordenada y moderna de la información personal y/o laboral de su propietario.

El proyecto busca combinar:

* Presentación profesional.
* Diseño web moderno.
* Información organizada.
* Experiencia de usuario clara.
* Adaptabilidad a distintos dispositivos.
* Navegación sencilla.
* Identidad visual coherente.
* Publicación web mediante GitHub Pages.

La estructura está pensada para que la información pueda ser presentada de manera directa y visual, facilitando que los visitantes conozcan el perfil profesional y sus principales antecedentes.

---

## ✨ Características

### 🎯 Presentación profesional

Diseño orientado a proyectar una imagen seria, moderna y profesional, priorizando la correcta organización de la información.

### 📱 Diseño adaptable

La interfaz está planteada bajo criterios de **diseño responsive**, permitiendo su visualización en:

* 🖥️ Computadores.
* 💻 Notebooks.
* 📱 Teléfonos móviles.
* 📲 Tablets.

### 🧭 Navegación intuitiva

La estructura del sitio facilita el acceso a las diferentes áreas de información sin sobrecargar visualmente la interfaz.

### 🎨 Identidad visual

El proyecto utiliza una presentación visual cuidada, procurando mantener coherencia entre tipografías, espacios, elementos gráficos y contenido.

### ⚡ Experiencia de usuario

Se prioriza una experiencia sencilla y directa, evitando elementos innecesarios que puedan dificultar la navegación.

### 🌎 Publicación mediante GitHub Pages

El sitio se encuentra alojado mediante **GitHub Pages**, permitiendo disponer de una dirección web pública y accesible.

## 💻 Ejecución local

Si deseas visualizar el proyecto de manera local, puedes clonar el repositorio:

```bash
git clone https://github.com/emide-soporte/perfil_profesional.git
```

Luego ingresa al directorio:

```bash
cd perfil_profesional
```

Y abre el archivo:

```text
index.html
```

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto mediante un servidor local.
